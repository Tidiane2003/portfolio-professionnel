PAIEMENT WAVE
Paiement

Intégration Wave API

L'API Wave permet d'initier des paiements mobile directement depuis Flutter. Checkout sessions, webhooks de confirmation, et remboursements automatiques.

⚡ Flux de paiement Wave
1
User tape "Payer avec Wave"
Flutter envoie une requête à l'API Node.js avec le montant et l'orderId.
2
Node.js crée une Checkout Session
POST /v1/checkout/sessions → Wave API retourne une URL de paiement unique.
3
Redirect vers Wave
Flutter ouvre l'URL Wave via url_launcher. L'utilisateur confirme sur son app Wave.
4
Webhook confirmation
Wave envoie un POST webhook à notre API. On vérifie la signature HMAC-SHA256.
5
Commande validée
MongoDB mis à jour. FCM notification envoyée au buyer et au seller. Deep link vers MarketSN.

routes/payment.routes.js — Webhook Wave
// Vérification signature webhook Wave (HMAC-SHA256) const verifyWaveWebhook = (req, res, next) => { const signature = req.headers['wave-signature']; const secret = process.env.WAVE_WEBHOOK_SECRET; const payload = JSON.stringify(req.body); const expected = crypto .createHmac('sha256', secret) .update(payload) .digest('hex'); if (signature !== `sha256=${expected}`) { return res.status(401).json({ error: 'Invalid signature' }); } next(); }; // Handler webhook paiement réussi router.post('/webhook/wave', verifyWaveWebhook, async (req, res) => { const { event, data } = req.body; if (event === 'checkout.session.completed') { const order = await Order.findOneAndUpdate( { _id: data.client_reference }, { status: 'paid', paymentId: data.id }, { new: true } ); // Notifier buyer + seller via FCM await sendPushNotification(order.buyerId, { title: 'Paiement confirmé ✅', body: `Commande #${order._id} payée via Wave` }); } res.json({ received: true }); });

Ce que MarketSN fait

01 // CATALOG
🏪
Boutique Vendeur
Chaque vendeur crée sa boutique en 5 min. Catalogue illimité, gestion photos via Cloudinary, stock temps réel. Approbation admin automatique.
02 // PAYMENT
💳
Wave & Orange Money
Paiement mobile sénégalais natif via Wave API. Webhooks sécurisés HMAC. Confirmation instantanée. Remboursement automatique si échec.
03 // DELIVERY
🚴
Suivi livraison GPS
Réseau livreurs partenaires. Suivi GPS temps réel via Firestore. Notifications push à chaque étape. Zone couverte : Dakar + Banlieue.
04 // CHAT
💬
Messagerie temps réel
Chat acheteur-vendeur via Firestore StreamBuilder. Photos, négociation prix, coordination livraison. Historique complet.
05 // AUTH
🔐
Auth sécurisée
Firebase Auth multi-méthodes. OTP par SMS. JWT sécurisé côté API. Rôles (acheteur / vendeur / admin). Vérification KYC vendeur.
06 // SELLER
📊
Dashboard Vendeur
Analytics ventes, revenus journaliers, produits les + vus, avis clients. Gestion commandes entrantes. Déployé sur Render.
