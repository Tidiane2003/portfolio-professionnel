Fonctionnalités

Conçu pour être réutilisé

Chaque fonctionnalité a été pensée pour les PME en Afrique de l'Ouest.

Design System complet
Composants UI réutilisables, thème clair/sombre, variables CSS, icônes cohérentes. Personnalisable en 5 minutes.
Graphiques & KPIs
Tableaux de bord avec Chart.js : courbes, barres, camemberts, jauges. Export CSV et PDF intégrés.
Gestion des rôles
5 niveaux d'accès. Permissions granulaires par module. Audit log de toutes les actions.
100% Responsive
Optimisé desktop, tablette et mobile. Sidebar rétractable, tableaux scrollables, modales adaptatives.
Multi-devises & langues
Support F CFA, EUR, USD. Interface en français et anglais. Formats adaptés à l'Afrique de l'Ouest.
API REST incluse
Backend Node.js + Express + MongoDB prêt à déployer. Documentation Swagger complète.
Stack technique

Technologies utilisées

Des outils éprouvés, documentés, faciles à déployer sur des serveurs locaux ou cloud.

UI Framework
React 18
Hooks, Context API, lazy loading des modules. Architecture par composants réutilisables.
Visualisation
Chart.js 4
Graphiques responsive, animés, avec support multi-datasets et export image.
Styling
Tailwind CSS
Design system utilitaire avec tokens personnalisés. Dark mode natif et thèmes marque.
Backend
Node.js + Express
API REST complète. Middleware auth, validation, rate limiting. Documentation Swagger auto.
Base de données
MongoDB + Mongoose
Schémas flexibles, indexation optimisée, migrations versionnées. Backup automatique.
Authentification
Firebase Auth
Connexion email/password, Google SSO. Sessions sécurisées avec refresh tokens JWT.
